# v2 — 真·老虎机（1950s 木质机械拟物）

用户反馈推翻 v1 极简壳：要真老虎机的感觉，拟物，视觉听觉炫酷。
方向：纯老虎机玩法（符号轴+中线判定+金币）× 1950s 木质黄铜机械风。
生成艺术（v1 的 8 算法）保留作 **JACKPOT 777 彩蛋**：全屏头奖海报，可截图。

## 核心循环（~6 秒/轮）

投币 clink → 拉杆臂下拉（棘轮）→ 释放（弹簧）→ 三轴滚动（whirr+tick）→
依次锁定 clunk → 中线判定 → 铃响 + 金币掉托盘 + count-up → 再拉。

## 数值（config.js，蒙特卡洛验证后落定）

固定注 5 币，开局 100 币。符号带 20 格/轴（真实机械做法，RTP 可精确算）：

```
Reel1: C5 L5 M4 B3 R2 S1
Reel2: C4 L5 M4 B3 R2 S2
Reel3: C4 L5 M4 B3 R2 S2
（C=樱桃 L=柠檬 M=西瓜 B=铃铛 R=BAR S=7）
```

赔付（中线，coins，bet=5）：

| 组合 | 赔付 | 概率 |
|---|---|---|
| 7×3 JACKPOT | 1000 (200×) | 4/8000 = 1/2000 |
| BAR×3 | 400 (80×) | 8/8000 |
| 铃×3 | 150 (30×) | 27/8000 |
| 瓜×3 | 90 (18×) | 64/8000 |
| 柠×3 | 70 (14×) | 125/8000 |
| 樱×3 | 30 (6×) | 80/8000 |
| 樱×2（左起） | 15 (3×) | 320/8000 |
| 樱×1（左起） | 3 (0.6×) | 1600/8000 |

理论 RTP ≈ 94.4%，命中率 ≈ 27.9%。樱桃按左起连算（经典规则）。

**软保底**：连续 6 次空手 → 下次必中小奖（构造樱桃停位）。压霉运尾，RTP 实效 ≈ 96-97%。
**Near-miss**：轴1轴2 已停 7-7 且轴3 自然停位非 7 → 改停在 7 的相邻格（窗口上/下行可见 7）。
不改赔付概率（本来就不中），只改"差一点"的可见性。
**破产**：币 < 5 → 老板娘赊账 +100，记欠账。净胜 = 币 − 欠账，显示在机器铭牌小窗。

## 拟物视觉（1950s 木质+黄铜）

- 机柜：木纹侧板+顶冠（CSS 渐变木纹），黄铜饰条/铆钉，铭牌「VIBE SLOT · EST. 1952」
- 赔率表：机顶玻璃面板印符号×赔率，中奖行点亮闪烁
- 转轴窗：玻璃罩高光反光；圆柱曲率——3 行可见，中行大而亮、上下行压缩压暗；滚动时模糊
- 符号：内联 SVG 手绘风（樱桃/柠檬/西瓜/铃铛/BAR 字牌/红 7）
- 拉杆：**右侧真拉杆臂**，红球头，拖拽使杆绕轴旋转下拉，过阈值释放回弹触发
- 中线：窗口横贯黄铜 payline
- 金币托盘：底部金属托盘，赢钱金币掉落弹跳（DOM 硬币）+ 余额 count-up
- 灯泡：顶冠黄铜灯珠圈，中奖按档位闪，JACKPOT 旋转爆闪
- JACKPOT：777 → 灯爆闪+钟声 → 全屏生成艺术头奖海报（复用 v1 算法，随机组合）＋金额＋可截图
